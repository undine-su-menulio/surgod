# Сургодь — сайт для GitHub Pages

Это готовый статический сайт. Главная страница — `index.html`.
Таблицы, поэма и галереи работают без Python, Flask и базы данных.
После оглавления встроено видео Nuno; для его просмотра нужен интернет.

## Загрузка через сайт GitHub

1. Создайте репозиторий на GitHub, например `surgod`. Для бесплатной
   публикации через GitHub Pages выберите публичный репозиторий (Public).
2. Распакуйте `surgod_github_pages.zip` на компьютере.
3. В репозитории нажмите **Add file → Upload files**. Перетащите содержимое
   распакованной папки, сохраняя вложенные папки. `index.html` должен находиться
   в корне репозитория, а не внутри дополнительной папки `github_pages`.
4. Нажмите **Commit changes**. Если файлов много, загрузите папки несколькими
   партиями. Скрытый файл `.nojekyll` тоже желательно загрузить.
5. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите
   **Source: Deploy from a branch**, ветку **main**, папку **/ (root)**,
   затем нажмите **Save**.
6. Дождитесь успешного развёртывания (обычно несколько минут). Адрес будет
   указан на этой же странице: `https://ВАШ-ЛОГИН.github.io/surgod/`.

ZIP нужен для передачи сайта: загрузка одного ZIP в репозиторий не публикует
его содержимое. Загружать нужно распакованные файлы.

Если браузер GitHub отклоняет большую партию файлов, используйте GitHub Desktop:
клонируйте репозиторий, скопируйте в него всё содержимое пакета, выполните
Commit to main и Push origin, затем настройте Pages, как описано выше.

## Что включено

- `index.html` — главная страница; `surgod_wiki.html` — совместимый второй адрес.
- Изображения, миниатюры, карты, справки и исходные CSV.
- PDF-источники не включены: в сносках и библиографии стоят ссылки на онлайн-источники.
- `deployment_manifest.json` — размеры и контрольные суммы опубликованных файлов.
- `.nojekyll` — отключение обработки сайта Jekyll.

Имена файлов и структура папок значимы: не переименовывайте их отдельно от ссылок.
Ссылки относительные: сайт подходит и для репозитория проекта, и для корневого
репозитория `ВАШ-ЛОГИН.github.io`.

Серверный исследовательский рабочий стол Flask не входит в публикацию.
Источники и условия использования изображений сохранены в подписях статьи.
В `publications.csv` сохранён исследовательский каталог: указанные в нём пути
относятся к локальному исследовательскому архиву, а не к файлам этого сайта.
Для чтения публикаций используйте колонку `url` или сноски статьи.

## Обновление

В исходном исследовательском проекте выполните:

```powershell
python build_surgod_wiki.py
python build_github_pages.py
```

После этого замените опубликованные файлы содержимым нового пакета.
