# Основания декоративного орнамента

Проверено 22.10.2026. Задача — сдержанное оформление локальной статьи о татарском селе Сургодь в Мордовии.

## Источники

1. Г. Ф. Валеева-Сулейманова. **Орнамент** // Татарская энциклопедия Tatarica. https://tatarica.org/ru/razdely/kultura/iskusstvo/izobrazitelnoe-iskusstvo-i-dpi/ornament — прочитан полный текст электронной статьи; [сохранённая страница](sources/ornament_tatarica.html), [текст](sources/ornament_tatarica.txt). Перечислены тюльпан, трилистник, цветочная розетка, волнообразный побег; описаны криволинейные формы и ленточная композиция.
2. Г. Ф. Валеева-Сулейманова. **Вышивка** // Tatarica. https://tatarica.org/ru/razdely/narody/tatary/narodnoe-iskusstvo/vyshivka — прочитан полный текст; [страница](sources/embroidery_tatarica.html), [текст](sources/embroidery_tatarica.txt). Для татарской вышивки описаны цветочно-растительные орнаменты, включая тюльпан, ленточные и букетные композиции; среди популярных цветов названы зелёный и золотисто-жёлтый.
3. Л. Ф. Фасхутдинова. **Золотное шитье татар-мишарей: особенности техники и орнамента** // Этнографическое обозрение. 2015. № 4. С. 169–176. https://eo.iea.ras.ru/article/9393/ — проверены официальная карточка и аннотация, не полный текст статьи; [страница](sources/mishar_goldwork.html), [текст](sources/mishar_goldwork.txt). Автор выделяет особый мишарский стиль золотного шитья и отмечает параллели с искусством других татарских групп и русских. По одной аннотации нельзя установить набор мотивов именно Сургоди или Мордовии.

Исходные HTML сохранены без изменений, SHA-256 и адреса — в `download_manifest.json`. Статьи об орнаменте не добавлены в библиографию публикаций, непосредственно упоминающих Сургодь.

## Вывод для оформления

У татар-мишарей исследователями выделяются локальные особенности орнаментального искусства. Вместе с тем отдельный характерный узор **именно Сургоди или Торбеевского района** по проверенным источникам не установлен. Мордовские (эрзянские/мокшанские) узоры не использованы как замена татарской традиции.

Создан [новый SVG](tatar_floral_ornament.svg): центральный тюльпан, парные листья, волнообразный побег, небольшие ромбовидные розетки. Это свободная современная стилизация общетатарских растительных мотивов, а не копирование музейной вещи и не заявленная реконструкция местной вышивки. Приглушённые зелёный и золотистый цвета — дизайнерское решение для спокойного чтения, не историческая реконструкция палитры.

SVG встроен в CSS статьи как data URI: тонкая кайма над заголовком и у подвала, без узора за основным текстом. Автор рисунка — OpenCode, 22.10.2026. Воспроизводится генератором `build_surgod_wiki.py` через `wiki_design.py`.
